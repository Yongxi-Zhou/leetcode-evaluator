## Build Instructions

```bash
# Anonymous ARR submission (adds line numbers, hides author)
./build.sh anon       # outputs main-anon.pdf

# Preprint / arXiv
./build.sh preprint   # outputs main-preprint.pdf

# Camera-ready
./build.sh final      # outputs main-final.pdf
```

**Before building**, figures must be present at `publication/figures/`. They are gitignored at the repo root (`output/` is in `.gitignore`) and must be copied manually:
```bash
mkdir -p publication/figures
cp output/aggregate/figures/paper_figure*.png publication/figures/
```
